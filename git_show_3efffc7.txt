    fix: implement all audit findings (Bugs 1–12, 14)
    
    Bug 1 (CRITICAL): execution.py api_quick_execute — kill_switch=False
      hardcode replaced with _r.kill_switch() (was bypassing kill switch
      in quick execute path).
    
    Bug 2 (CRITICAL): Wire guardian.pre_trade_check() into all three
      production execution callsites (execution.py quick/standard/scalp
      routes) and auto_trader._execute_signal(). The guardian was fully
      implemented but never called from any live code path.
    
    Bug 3 (HIGH): auto_trader timestamp re-stamp now guarded by
      AUTO_TRADE_MAX_SCAN_AGE_SEC (default 900s). Signals from a prior
      scan cycle (> 15 min old) are no longer re-stamped and will be
      rejected by risk_check's STALE_SIGNAL gate.
    
    Bug 4 (HIGH): auto_trader._write_audit() now records max_score,
      score_pct, factors_json, edge_prob, style, fee_cost — matching
      the fields written by the manual execution path.
    
    Bug 5 (HIGH): Engine B quick-execute audit row now uses
      engine_b.get("score") instead of sig.get("confluenceScore").
      Mixed-scale (A=0–3.0 vs B=0–100) values were corrupting analytics.
    
    Bug 7 (MEDIUM): Remove dead-code expressions d1["snap"] and
      h1["snap"] in scoring.py calc_confluence that evaluated and
      discarded results.
    
    Bug 8 (MEDIUM): Fix asymmetric bull/bear for SHORT signals in
      scoring.py. Was setting bull=score AND bear=score for SHORT;
      now bull=0.0 for SHORT.
    
    Bug 10 (MEDIUM): Replace bare sqlite3.connect()+explicit close()
      with context managers in divergence_monitor.check_divergence()
      and divergence_report() — prevents connection leaks on exception.
    
    Bug 11 (MEDIUM): stability_monitor SSI cold-start no longer
      defaults to 50.0 (YELLOW). Returns ssi=None, band="NO_DATA"
      when no scored events exist. _system_ssi updated to propagate
      NO_DATA correctly.
    
    Bug 12 (MEDIUM): meta_learner._recent_slippage_samples() now
      SELECTs the engine column and uses it directly in _infer_engine(),
      falling back to heuristics only for older rows where engine IS NULL.
    
    Bug 14 (LOW): Rename loop variable utc_hour → _bar_hour inside
      forex_scoring._london_breakout_score() to eliminate shadowing of
      the outer function parameter of the same name.
