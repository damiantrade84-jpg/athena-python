# Archived documentation

Files here are **historical notes only**. They are not loaded as Codex/Cursor startup instructions.

- Active repo rules: **`AGENTS.md`** at repo root.
- On-demand workflows: **`.agents/skills/<name>/SKILL.md`**.
- Memory policy: **`docs/codex-memory-policy.md`**.

When archiving old `memory.md` / `memories.md` content, use names like `memory.archive.md` or `memories.archive.md` and include a top-of-file notice that the file is archived and must not be used as active agent guidance.
